## 端口分配说明

| 用途 | 宿主机端口 | 容器端口 | 说明 |
| ---- | ---------- | -------- | ---- |
| 后端 API | **39080** | 8080 | 在安全组 39000-40000 范围内 |
| MySQL 外部 | 13306 | 3306 | 远程连接用 |
| 宝塔面板 | 8888 | - | 已放行 |
| SSH | 22 | - | 已放行 |
| 前端开发 | 8081 | - | 本地仅限 |

> 💡 后端 API 使用 39080 而非默认的 8080，避免与其他项目冲突。
> 安全组已放行 `39000-40000` 端口范围。
