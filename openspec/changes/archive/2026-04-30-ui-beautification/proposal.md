## Why

当前农场管理系统 UI 已经建立设计系统（myCSS.css），登录页面已完成美化，但大部分业务页面仍使用基础样式。需要系统性地完成整个前端的美化工作，提供一致的用户体验。

## What Changes

- 完成所有 Navbar 组件（Header）的美化，统一风格
- 美化 AlertDialog 全局提示组件
- 美化所有业务页面视图（customer、manager、staff、supermanager）
- 确保所有页面使用统一的设计令牌和组件样式
- 优化响应式布局和交互细节

## Capabilities

### New Capabilities
- `ui-beautification`: 前端界面美化能力，涵盖所有 UI 组件和页面视图

### Modified Capabilities
- 无

## Impact

- 修改文件：`frontend/src/` 下的所有 Vue 组件
- 样式文件：`frontend/src/assets/css/myCSS.css`（已存在）
- 使用技能：vue、ui-ux-pro-max
